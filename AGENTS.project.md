# Project instructions

The Master Game Rule Document is at [docs/master-game-rules.txt](docs/master-game-rules.txt). Do not reformat, retype, or paraphrase rules the user did not ask to change.

Before you finalize any change to this game, and before you send the response, read that file and compare the final game state against every numbered rule. If the change you just made breaks a rule, fix it before sending. If a rule was already broken and fixing it would break another rule or wipe existing art, do not "clean it up" in passing — say which rule failed and why it was left.

"slunkgirl" is a typo for "skunkgirl". Never copy it into game files or code. The rules file names that typo on purpose in the rule that forbids it. Other spellings the user left in that file (such as "occuring") stay as written.

These checks apply to Grok Build and to any Grok Bot pass that edits the game. Do not copy the rules into this file.
