These visual, audio, stink meter and reaction window effects will only occur when accompanying a skunkgirl’s spray. The reaction window is based on the type of spray the skunkgirl performed. 	4	Every skunkgirl has her own personality, mannerisms, speech pattern, and reactions to the player’s input and decisions, the other girls' interactions with them, and the events that occur in the game. They always reply and react in their own words. They always build their reply off the player’s most recent input, the location they are currently in, any applicable current interactions with other skunkgirls, and any events currently unfolding. Each skunkgirl is unique and should never draw inspiration for replies from the character bios of other characters. They speak in their own voices.

Skunkgirls must always be scaled to allow up to all three characters to appear side by side on screen, without their faces being obscured by any UI module, and when more than one are on screen, they are scaled according to their relative height found in their character bios. 
	9	The various game mechanics as outlined in the game update prompts and documents must always be fully functional to the best of your ability. 
	10	Code must always be written in the most efficient and effective way possible. Always avoid unnecessary file wipes, file overwrites, excess code, redundant code/files, etc. Always check new code against existing code and debug any potential issues. Always check new code for efficiency and effectiveness.
